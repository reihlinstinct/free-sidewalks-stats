# Accessibility statement

We want free-sidewalks-stats to be usable by everyone. Our target is WCAG 2.2 level AA for
user-facing content and interfaces.

## What we do

- The project publishes a static Hebrew (RTL) dashboard: plain HTML, no external scripts, trackers or image assets.
- Semantic markup and keyboard-navigable content.
- Readable contrast and scalable text.
- We do not run automated accessibility tests in CI today; changes are reviewed manually on desktop and mobile.

## Known limitations

Accessibility work is ongoing. If something blocks you, we want to know.

## Feedback

Report an accessibility problem by opening an issue:
https://github.com/reihlinstinct/free-sidewalks-stats/issues/new/choose
If the report is sensitive, use a private security advisory instead:
https://github.com/reihlinstinct/free-sidewalks-stats/security/advisories/new
